## Summary

Enhance the Contracting Warehouse ERP Material Catalog with advanced inventory control capabilities:
1. **Intelligent Stock Filtering**: Filter materials by safety stock status (`currentStock <= minStock`) and arbitrary maximum quantity threshold ($CurrentStock \le X$) using native Prisma 6 field-to-field database queries.
2. **Universal Image Upload Pipeline**: Support all standard modern web image formats (AVIF, JFIF, WebP, SVG, BMP, PNG, JPEG) with extension fallback and unified API response properties (`url` and `imageUrl`).
3. **Interactive Multi-Selection & Formatted Excel/CSV Reorder Report**: Row and header checkboxes, floating selection bar, and formal UTF-8 BOM Excel report with company letterhead, metadata, and auto-calculated shortage/reorder deficit ($\max(0, \text{minStock} - \text{currentStock})$).
4. **Interactive Full Pagination**: Complete pagination controls (Previous/Next, page numbers, page size dropdown 10/20/50/100, record count) with multi-page selection retention.

## Technical Context

**Language/Version**: TypeScript 5.x / Next.js 15.1.4 (React 19 App Router)
**Primary Dependencies**: `prisma` (6.2.1), `lucide-react`, `motion` (Framer Motion), `sonner`, `react-hook-form`, `zod`
**Storage**: PostgreSQL with Prisma ORM
**Testing**: Static TypeScript checks (`tsc --noEmit`), manual validation scenarios (`quickstart.md`)
**Target Platform**: Desktop & Mobile modern web browsers
**Project Type**: Full-stack Next.js App Router Web Application
**Performance Goals**: Stock queries and pagination transitions < 150ms; CSV download generation < 500ms; Image uploads < 1.5s
**Constraints**: Zero data loss, immutable audit ledger, strict domain terminology (Material In / Material Out), UTF-8 BOM encoding for Excel Arabic support
