# Contract: Bilingual i18n Localization Contract

## Supported Locales
- `en`: English (Default LTR, `dir="ltr"`)
- `ar`: Arabic (RTL, `dir="rtl"`, Cairo font family)

- SKUs (e.g. `EGY-15200001`): `<span dir="ltr" className="font-mono">...</span>`
- Voucher references (e.g. `IN-20261029-001`): `<span dir="ltr" className="font-mono">...</span>`
- Numeric quantities and timestamps: `<span dir="ltr" className="tabular-nums">...</span>`
