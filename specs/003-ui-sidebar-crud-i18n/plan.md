# Implementation Plan: Enterprise UI Layout, Complete CRUD, and Bilingual Arabic/English

**Branch**: `003-ui-sidebar-crud-i18n` | **Date**: 2026-10-29 | **Spec**: [spec.md](./spec.md)

**Input**: User description: "Upgrade design with a collapsible Sidebar layout, fluid animations, full Arabic and English bilingual localization with RTL support, and complete CRUD operations (Add, View Details, Edit, Delete) for all modules (Materials, Categories, Units, Vouchers) along with enhanced UX like printable vouchers and export."

## Summary

Deliver an enterprise-grade ERP user experience for Sinoma Contracting Warehouse:
1. **Collapsible Animated Sidebar**: Desktop collapsible sidebar (256px expanded / 72px icon rail) with micro-interactions, tooltips, and mobile drawer.
2. **Bilingual Localization (i18n)**: Seamless client-side language switching between English (`en`) and Arabic (`ar`) with dynamic document direction (`dir="rtl"` / `dir="ltr"`), Cairo font integration, and strict domain terminology enforcement.
3. **Comprehensive CRUD**:
   - Materials: Full edit modal and safe deletion with transaction history guard.
   - Categories & Units: Full edit modals and safe deletion with assigned materials guard.
   - Vouchers: Detailed inspection modal, printable A4 gate passes with official signature blocks, and atomic cancellation rollback with compensating `ADJUSTMENT` ledger logs.
4. **Data Export**: UTF-8 CSV exports for Catalog and Ledger.

## Technical Context

**Language/Version**: TypeScript 5.x / Next.js 15.1.4 (React 19 App Router)
**Primary Dependencies**: `motion` (Framer Motion), `next-themes`, `lucide-react`, `sonner`, `react-hook-form`, `zod`, `@prisma/client`
**Storage**: PostgreSQL with Prisma ORM
**Testing**: Manual test suite & quickstart verification guide (`quickstart.md`), TypeScript static verification (`tsc --noEmit`)
**Target Platform**: Modern desktop & mobile browsers (Edge, Chrome, Safari, Firefox)
**Project Type**: Web application (Next.js App Router full-stack)
**Performance Goals**: Language switch < 50ms without page reload; Sidebar transitions 60fps; Voucher cancellation < 300ms
**Constraints**: Invariant stock balances (never negative); Strict domain terminology (Material In / Material Out, strictly no "Goods In" / "Goods Out"); Preserved LTR for SKU codes and numbers in RTL mode
**Scale/Scope**: 7 primary routes, 5 database entities, full bilingual coverage

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

- [x] **I. Full-Stack Next.js Architecture**: Server Actions handle database mutations; React Client components manage responsive sidebar, modal drawers, and language context.
- [x] **II. PostgreSQL Relational Integrity & Transactional Invariance**: All voucher cancellations execute in `prisma.$transaction`, ensuring currentStock rollbacks and `ADJUSTMENT` ledger entries are atomic.
- [x] **III. Type-Safe Form Management & Reactive UI Feedback**: Edit modals use Zod schemas and trigger Sonner toasts on all operations.
- [x] **IV. Ubiquitous Domain Terminology**: Strict enforcement of "Material In" & "Material Out" (and Arabic: "استلام وتوريد المواد" / "صرف وتوزيع المواد"). Zero occurrences of "Goods In" or "Goods Out".
- [x] **V. Scalable System Architecture & Audit Trails**: Cancellations append immutable `ADJUSTMENT` ledger entries preserving the audit trail without destructive deletes.
